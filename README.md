# CryptAnamoBay (cryptanamobay.com)

Static site (no login) for tracking alleged/charged/convicted crypto misconduct with source citations.

## What this is
- A public directory with filtering + search
- Each profile is **fact-forward** (neutral language) and backed by citations
- Clear labeling: **Alleged / Charged / Convicted / Settled / Sanctioned**

## Run locally
Just open `index.html` in a browser.

## Deploy
Any static host works:
- Cloudflare Pages
- Netlify
- Vercel (static)
- GitHub Pages

## Data
Edit `data/profiles.json`.

This project includes disclaimers and a corrections/contact path, but you should still review with counsel if you’re going to publish allegations about identifiable individuals.
